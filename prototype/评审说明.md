# 投研大盘数据平台 · Tabler 交互原型 v5.3 评审说明

## 一、原型定位

**单文件、自包含、可交互**的高保真原型：`prototype/index.html`，双击即可离线打开，**不依赖同目录任何外部资源**。用于评审新版 UI 与交互，**未改动任何生产代码**。

- 技术：Tabler 1.2 + Tabler Icons 3.31（CSS 与字体已 base64 内联）、ECharts（内联）、样例数据（内联）
- 数据：生产真实数据快照的少量抽样（每序列约 24 点，表格 3~8 行）
- 全部按钮、筛选、分页、弹窗、图表联动均为本地模拟，点击有真实反馈
