触发逻辑说明

  1. 触发条件：服务运行时按上方调度配置每日到点触发一次，同一天只触发一次；未启用/未到点/今日已触发/任务占用时不执行，日志中给出原因。
  2. 步骤 1~5：调度器依次完成 触发 → 提交采集任务 → 宏观/ETF/指数采集 → 写 SQLite 业务表（幂等 upsert）→ 采集完成统计，全程写入实时监控日志。
  3. 步骤 6/6 派生增量重算：采集完成后，按本次 run_id 读取本次写入 macro_observation 的原始 (指标, 月份)，经依赖映射（差分需上月、同比需去年同月、二阶差分需去年同月新增）推导受影响的派生 (指标, 月份)，只重算这些目标行并按 biz_key=派生代码+YYYYMM 幂等 upsert，不做全量重复计算、不删整表；派生表为空（首次）时自动回退全量建立基线。
  4. 手动重算（兜底）：「全部」全量重算并整表替换（清理陈旧口径行）；「按月」「按指标」按业务键幂等覆盖只影响目标子集。无论增量或局部，差分/同比分母始终基于全量原始值计算，不会因单月缺分母算错。
  5. 口径要点：进出口同比用官方累计；人民币贷款当月新增为余额差分；居民存款新增/同比多增为余额一阶/二阶差分；黄金当月新增为储备差分×31.1034768÷100（万盎司→吨，口径跳变已剔除）；社零环比用统计局官方季调值；社融存量取央行官方增速。
  6. 看板联动：数据看板与各派生指标图直接读取 derived_indicator，重算完成后自动生效；看板支持按日期范围筛选，宏观与 ETF 口径一致。

三类原始表：交易所概况 / 两融账户 / 全A个股快照。快照仅当日不可回溯，集中度与涨跌家数自采集日起累计。
全A成交额 = 沪成交金额(亿元) + 深成交金额(元)÷1e8
成交集中度(前5%) = 个股成交额降序前 5% 之和 ÷ 全A成交额 ×100% · 两融余额 = 融资余额 + 融券余额
融资余额占流通市值比 = 融资余额 ÷（沪流通市值 + 深流通市值÷1e8）×100% · 融资买入额占比 = 融资买入额 ÷ 全A成交额 ×100%
融资保证金比例 为政策阶梯常量（当前 80%），按交易日匹配生效值 · 涨跌家数 由快照涨跌幅统计
